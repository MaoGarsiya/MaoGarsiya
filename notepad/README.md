# Мой блокнот

Простой адаптивный блокнот для смартфонов. Работает в браузере без сервера и сохраняет заметки локально на устройстве.

## Возможности
- Создание, редактирование и удаление заметок
- Поиск по названию и тексту
- Сортировка по дате изменения
- Адаптивный интерфейс для смартфонов
- Хранение данных в localStorage браузера

## Запуск
Откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root)**.

## Важно
Это веб-приложение, а не APK. Заметки хранятся только в текущем браузере на этом устройстве. Очистка данных браузера может удалить заметки; для переноса между устройствами нужна отдельная функция экспорта/синхронизации.
